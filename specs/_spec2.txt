2. Database Design Principles
Use these rules from the beginning:


    1. Every primary key is a UUID.
    2. Never expose sequential database IDs publicly.
    3. Store money using NUMERIC , never floating-point.
    4. Store timestamps in UTC.
    5. Use foreign keys.
    6. Use database constraints in addition to API validation.
    7. Use indexes for frequently searched columns.
    8. Use soft deletion where appropriate.
    9. Never store passwords in plaintext.
   10. Payment records must be immutable/auditable.
   11. Never trust values coming from the mobile application.
   12. Business verification and user permissions must be enforced server-side.

28. SQLAlchemy Base
Use SQLAlchemy 2.x style.



  from datetime import datetime
  from uuid import UUID, uuid4

  from sqlalchemy import DateTime, func
  from sqlalchemy.dialects.postgresql import UUID
  from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column



  class Base(DeclarativeBase):
      pass



  class UUIDMixin:
      id: Mapped[UUID] = mapped_column(
          UUID(as_uuid=True),
          primary_key=True,
          default=uuid4,
      )



  class TimestampMixin:
      created_at: Mapped[datetime] = mapped_column(
          DateTime(timezone=True),
          server_default=func.now(),
          nullable=False,
      )

       updated_at: Mapped[datetime] = mapped_column(
           DateTime(timezone=True),
           server_default=func.now(),
           onupdate=func.now(),




                                          26
         nullable=False,
     )




29. User Model

 from sqlalchemy import Boolean, String
 from sqlalchemy.orm import Mapped, mapped_column, relationship



 class User(UUIDMixin, TimestampMixin, Base):
     __tablename__ = "users"

     phone: Mapped[str] = mapped_column(
         String(20),
         unique=True,
         nullable=False,
         index=True,
     )

     email: Mapped[str | None] = mapped_column(
         String(255),
         unique=True,
         nullable=True,
     )

     status: Mapped[str] = mapped_column(
         String(20),
         default="ACTIVE",
         nullable=False,
     )

  from abc import ABC, abstractmethod



  class PaymentProvider(ABC):

              amount: Decimal,
              phone: str,
              reference: str,
          ):
              pass

          @abstractmethod
          async def check_status(
              self,
              reference: str,

                                                      48
            pass


        @abstractmethod
