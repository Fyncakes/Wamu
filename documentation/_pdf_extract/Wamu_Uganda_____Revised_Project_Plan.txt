     1. Executive Summary
     Wamu is Uganda's everyday app: one account for local business discovery, chat-based commerce,
     delivery, and mobility. The original vision was correct, but the execution sequence was wrong twice
     over.

     Mistake 1: Building messaging first would compete directly with WhatsApp without a compelling
     reason to switch.

     Mistake 2: Building a commerce catalog first would look like Jumia — a warehouse, not a
     neighborhood.

     This revised plan corrects both. Wamu will build the transaction loop first — but the transaction
     loop is conversational and social, not catalog-based:

         Discover → Chat → Buy → Pay → Deliver → Review

     Discovery happens through short videos of local businesses. Commerce happens inside chat.
     Payment happens via mobile money. Delivery happens through a named, verified rider. The same
     rider network powers passenger mobility. One account carries every role.

     The goal is not to clone WhatsApp, TikTok, SafeBoda, or Jumia. The goal is to make them obsolete
     inside one connected ecosystem.


             "Jumia built a warehouse. Wamu is building a neighborhood."

     3.1 Core Principles
           Transaction-first: Every feature must support a real transaction.
           Conversation-first: Chat is the store. Cart is replaced by conversation. Checkout is replaced
           by order cards.

           Discovery-first: Short video is the home screen, not a product grid.
           Uganda-first: Designed for local payments, connectivity, and mobility.

           Trust by design: Verification, security, and privacy built into the architecture.

           Shared infrastructure: One rider network, one payment abstraction, one location service.

           Phased expansion: Prove one loop, then add reasons to stay.




     4. The Core Value Loop

       Discover              →   Chat   →     Buy    →       Pay       →        Deliver   →    Review

     This is the heart of Wamu. Everything else is an extension.

       1. Discover: Customer scrolls a vertical short-video feed of local businesses.

       2. Chat: Customer taps "Chat to Order" and opens a conversation with the merchant.

       3. Buy: Customer negotiates, selects products, and receives an order card in chat.

       4. Pay: Customer pays via MTN MoMo, Airtel Money, or cash on delivery.
       5. Deliver: A named, verified rider picks up and delivers the order. Customer tracks live.

       6. Review: Customer rates the merchant and the rider.

     Once this loop works repeatedly, Wamu adds:

           Passenger mobility via the same rider network

           Merchant settlement and rider payouts

           Groups and communities for merchants
           Intelligence and personalization

     6. The Demo-First Strategy
     The first production artifact is not a launchable product. It is a fundable demo.

     The demo must prove three things in under 10 minutes:

       1. The loop works — Discover → Chat → Buy → Pay → Deliver → Review, end to end.
       2. It is Uganda-first — mobile money, boda riders, local merchants, low data.

       3. It is not Jumia — video feed, chat ordering, named verified rider, shared rider network.
